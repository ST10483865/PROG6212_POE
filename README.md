# Race Application

## Project Overview

The Race Application is a web-based system developed using ASP.NET Core MVC and Web API. The application provides user authentication functionality, allowing users to register for an account and securely log in using their credentials.

The project consists of two main components: **Race API** and **Race_Web**. The API handles backend functionality, while the web application provides the user interface through which users interact with the system.

## Project Components

### 1. Race API
The Race API is responsible for handling backend operations and processing requests from the web application.

### 2. Race_Web
Race_Web is the frontend web application developed using ASP.NET Core MVC. It provides the interface for users to register and log in.

## Features

- User registration.
- User login and authentication.
- Communication between the web application and the API.
- Database integration for managing user information.
- Responsive user interface.

## Technologies Used

The project was developed using the following technologies:

- **C#** – Backend programming language.
- **ASP.NET Core MVC** – Web application framework.
- **ASP.NET Core Web API** – Backend API development.
- **HTML5** – Web page structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Client-side functionality.
- **SQL Server** – Database management.
- **Microsoft Azure** – Cloud platform and services.
- **Visual Studio 2022** – Development environment.

## Project Structure

The solution contains two main projects:

- **Race API** – Handles backend functionality and API requests.
- **Race_Web*8 – Handles the user interface and user interactions.

## Development Environment

The application was developed using Microsoft Visual Studio 2022.

## Running the Application

1. Clone the repository from GitHub.
2. Open the solution file (`.sln`) in Visual Studio 2022.
3. Ensure that the required NuGet packages are installed.
4. Configure the database connection string.
5. Ensure that the SQL Server database is available.
6. Configure the API and web application to communicate using the correct API URL.
7. Set the appropriate startup projects.
8. Run the application using Visual Studio 2022.
